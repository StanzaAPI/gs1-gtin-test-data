# GS1 GTIN Test Data

GS1 GTIN-14 identifiers with correctly computed MOD-10 check digits, plus a GS1 element string with batch and expiry (AI 01/10/17).

Free to use under **CC0-1.0** (public domain dedication, no attribution required).

## Files

- `gs1-gtin-small.json`
- `gs1-gtin-small.csv`
- `gs1-gtin-medium.json`
- `gs1-gtin-medium.csv`
- `gs1-gtin-large.json`
- `gs1-gtin-large.csv`

Each size ships as JSON and CSV. The data is deterministic: the same size always
produces the same rows.
